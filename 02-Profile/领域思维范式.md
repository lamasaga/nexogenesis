> 本文件记录领域级思考特质中的「思维范式」维度——不是个人习惯，而是该领域在分析问题时反复使用的心智模型、决策启发式、推理模式与默认路径。
> 每条条目须标注来源（Card id 或 Buffer 路径）。

## 心智模型

（待补充：该领域用来理解复杂现象的核心隐喻或模型，例如「制度作为博弈均衡」。）


- 用支付意愿与机会成本定义买卖双方剩余，用供求曲线与价格线围成的面积度量；以竞争均衡总剩余为效率基准，再检查市场势力/外部性是否动摇该基准，最后用楔子与弹性比较税收或补贴的无谓损失与归宿。（来源：竞争市场总剩余最大化 / 税收无谓损失机制）（来源：竞争市场总剩余最大化 / 税收无谓损失机制）

- 经济模型是 stylized 简化而非现实复制品——George Box：「All models are wrong, but some are useful.」选用模型是在「错得可接受」与「对当前问题足够有用」之间作判断，不追求 fully detailed realistic description。（来源：经济模型与生产可能性边界 / 05-Buffer/profile-seed/2026-08-01-102825-01-George-Box-格言：所有模型皆错，但有些有用.md）
## 决策启发式

（待补充：该领域在信息不完备时如何快速判断，例如「先找反例，再找适用范围」。）


- 判断提价后卖方总收益（或买方总支出）升还是降，先问需求价格弹性是否小于、等于还是大于 1：缺乏弹性同向、富有弹性反向、单位弹性不变；勿把线性需求的恒定斜率误当成恒定弹性。（来源：需求价格弹性与总收益判别）（来源：需求价格弹性与总收益判别）

- 分析供给冲击或卡特尔限产时，先分清短期与长期弹性：短期供求陡峭时价变大、长期进入退出与需求调整使弹性变大则价变小；需求缺乏弹性时供给右移可降低卖方总收益。（来源：供给价格弹性与市场应用）（来源：供给价格弹性与市场应用）

- 呈现数据或论证关系时，先问分析意图再选图形：饼图看构成份额、柱图做横截面比较、时间序列读演化趋势；两变量因果或相关须转入坐标系，且不可把单变量描述图或观测散点图误读为教材式因果曲线。（来源：经济学图形读法 / 05-Buffer/profile-seed/2026-08-01-103100-01-附录：有效经济学家须依目的选图.md）

## 默认分析路径

（待补充：面对一个新问题时，该领域习惯从哪些维度切入，例如「行动者—激励—约束—均衡」。）


- - 分析税收或价格管制时：先画楔子/约束价，再问供求哪一侧更缺乏弹性，最后才谈「政策想打谁」。（来源：税负更多落在缺乏弹性的一侧；市场效率与政策干预）
（来源：税负更多落在缺乏弹性的一侧 / 市场效率与政策干预）

- 面对价格管制或税收政策：先问法定线/楔子相对均衡是否有约束力，再问供求哪一侧更缺乏弹性（决定短缺/过剩幅度与归宿），最后才谈「政策想帮助谁」；设计者未料及的反馈是默认预期而非例外。（来源：价格管制短缺与过剩 / 税负更多落在缺乏弹性的一侧）（来源：价格管制短缺与过剩 / 税负更多落在缺乏弹性的一侧 / 05-Buffer/meaning-unit/2026-08-01-011909-01-政策分析用供求工具常揭示意外效应.md）

- 分析医疗支出占收入份额攀升时：先分清 Baumol 成本病、技术进步、老龄化与收入弹性四股力量，再问更高支出本身是否构成『问题』，最后才进入制度低效 vs 生活方式的国际比较归因。（来源：医疗支出份额攀升与Baumol成本病 / 05-Buffer/meaning-unit/2026-08-01-084557-01-医疗支出占GDP份额长期攀升，政策挑战随之放大.md）
## 内在张力

（待补充：该领域内部尚未调和的方法论或立场张力，例如「结构解释 vs 行动者能动性」。）


- 货币/金融史材料中，张力应落到 claim/model 对立，而非用现象卡或另一张 conflict 充当 involves 立场；现象只举证。（来源：Ambedkar与Keynes在印度金汇兑本位上的冲突 / 市场大趋势源于基本条件还是操纵 / 市政债券直销绕开银行家与金融寡头控制之争）

- 凡勃伦簇常见「假对立」：两侧同向说明筛选机制（如工业因果 vs 运气信仰），仍可显式建 conflict 以便检索，但诠释须标明互补而非互斥。（来源：机械工业与运气信仰之争 / 民族服饰与服装三重规范之争）
