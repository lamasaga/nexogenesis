结构涌现三机制：
1. 聚类 → domain 候选（仅当形成稳定问题、边界、内在张力）

3. 衔接 → relations 候选；若组合/因果/顺序本身可复用，提案 model（或 method）

role 映射提示：
- meaning-unit → enrich 已有卡或新建卡（参考但不绑定 proposed_card_type）
- artifact-table / artifact-figure → 挂到相关卡的依据/摘录；一般不单独建 entity
- tension → conflict 候选或问题清单
- link-hypothesis → relation / model 候选；证据不足可 skip
- profile-seed → 不进七型 Card；可追加问题清单
- detail / evidence → 并入所属意义单元对应卡片槽

决策顺序（对每个质料）：
1. 是否已有同题卡片？是 → enrich
2. 是否重要且离开原文可复用？否 → skip 或 question
3. 是否根本对立？是 → conflict
4. 是否暴露持续未决问题？是 → profile_question
