　　活契约：`../body-structure.md`。

## 落点

| 位置 | 用途 |
|------|------|
| `schemes/default/card-exemplars/` | 方案源；`init` 复制到项目 |

## 反例（勿模仿）

- 领域卡只有枢纽名列表、没有肖像  
- 主张用分号串三条机制  
- 模型组件是名词子弹  
- claim/model 再套一层与核心重复的「导读」  
- conflict 开六条并列「核心分歧」
