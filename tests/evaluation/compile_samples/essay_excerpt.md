# 分析的诱惑与诚实的边界

我常常觉得，社会科学分析有一种隐秘的诱惑：它让你相信自己已经理解了某件事，仅仅因为你为这件事找到了一个连贯的叙述。一个政策失败了，我们立刻说那是因为"激励不相容"；一个社会运动崛起了，我们又说那是"身份认同的回归"。这些解释听起来都有道理，但它们往往是在事实已经发生后才组装起来的。

真正困难的问题不是"如何解释已经发生的事"，而是"在事前，哪些信号会让你改变看法"。我越来越倾向于认为，一个好的分析必须附带一个"反条件"：在什么证据下，这个判断会被推翻？如果没有这个反条件，分析就只是一种修辞——它说服别人，也说服自己。

这种诚实是有代价的。承认自己的判断可能错误，会让文章失去一部分锐气；反复讨论边界条件，会让读者感到疲惫。但我宁可要一种有保留的清晰，也不要那种看似确定实则空洞的断言。社科写作的伦理，也许不在于给出答案，而在于让追问的方式本身变得可见。

当然，这也带来一个张力：我们既希望自己的判断足够有力，能够被他人使用；又希望它足够谦虚，不会误导。如何在这两者之间找到平衡，我还没有满意的答案。
