# 金融实践卡：值得借鉴 vs 需要改

　　对照对象：早期金融实践卡（现置于 `参考原稿/`）。  
　　对照标准：现行以 `01-Cards/_meta/body-structure.md` 与 `card-exemplars/` 为准（本文件保留讨论纪要）。

---

## 值得借鉴（请保留进样例）

1. **模型正文真的在讲机制**  
　　`小院高墙…`、`管理-替代困境…`、`有闲阶级作为保守力量`：核心思想是完整段落，组件带职责说明，因果链可读，失效边界可观察。这正是 Ross 电报卡缺的东西——**不是领域问题，是写法问题**。

2. **主张可以是人话**  
　　`慈善改良组织攀比动机污染` 的「一句话主张」能朗读、一事一意，比 Ross「国内政治…」那句好用得多。

3. **现象卡写得出「模式」**  
　　`古雅措辞与繁冗正字法…`：模式描述清楚，实例具体，摘录对得上。适合当 phenomenon 样板。

4. **冲突卡结构干净**  
　　`投资银行家功能边界之争`：双方、分歧点、证据/代价、调和可能都在，involves 指向清楚。适合当 conflict 样板（开篇补 `## 诠释` 即可）。

5. **跨材料理论迁移**  
　　小院高墙 / 管理-替代把经典透镜用到当代案例，说明卡片可以服务「思维体套框架」，而不只是读书笔记——样例里应保留至少一张这类卡。

---

## 需要优化修改

1. **开篇按类型，勿万能导读**  
　　domain / phenomenon / conflict 用 `## 诠释`；claim / model 的开篇就是主张或核心思想——再套导读易重复。细则见 `00-槽位草案.md`。

2. **标题层级不统一**  
　　有的 `###`、有的 `##`。样例与契约统一用 `##`。

3. **关系边过载**  
　　小院高墙、管理-替代 frontmatter 关系过多，读卡干扰大。样例卡建议 **3～6 条**语义边；其余留给正式库。

4. **domains 堆叠**  
　　一张卡挂三四个领域，样例里改为 **一个主领域**（跨域用 relations 说明），避免「样卡领域身份」混乱。

5. **组件里中英夹杂、排版噪声**  
　　如 hoarding、sanctions 直接塞进中文句；样例改为中文或「中文（英文术语）」。

6. **仍缺「领域肖像」样板**  
　　金融侧有好的 claim/model/conflict，但没有一张让人一看就懂「这个领域在材料里长什么样」的 domain 样例。Veblen 域补一张。

7. **管理-替代 / 小院高墙偏「综述报告」**  
　　信息密度高是优点；作 digest 模仿时略长。样例版会略收，但**绝不压回电报**。

　　用户原稿已迁入 `参考原稿/管理-替代困境与安全-时间购买论之争.md`。  
　　敲定样例：`conflict-管理替代与时间购买-样例.md`。

| 原稿优点（保留） | 样例改动 |
|------------------|----------|
| 两造可运行、证据+代价、分层调和 | 加诠释；核心分歧收为 2 钉；单主领域；involves 瘦身；标明乙方为 system 构造对手；`##` 标题 |

　　理想 conflict = **该卡的对抗质量** + **银行家卡的结构克制**。
