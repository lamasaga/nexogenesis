### 核心表达

1886 年至 1904 年纽约市国民银行贷款数据显示，证券贷款（Advances on Securities）从低于商业票据迅速增长并远超商业票据，说明银行信贷越来越多地流向证券市场。

### 依据与细节

| 年份 | 商业票据（百万美元） | 证券贷款（百万美元） |
|---|---|---|
| 1886 | 146 | 107 |
| 1890 | 151 | 145 |
| 1892 | 160 | 183 |
| 1894 | 168 | 192 |
| 1896 | 151 | 162 |
| 1898 | 181 | 260 |
| 1900 | 185 | 384 |
| 1902 | 210 | 396 |
| 1903 | 239 | 391 |
| 1904 | 268 | 538 |

- 金额单位：百万美元。
- 1886 年证券贷款为商业票据的 73%；1904 年证券贷款为商业票据的 2.01 倍。
- 关键转折点：1898 年后证券贷款迅速拉开差距。
- 1898 年证券贷款（260）首次显著超过商业票据（181）。
- 1900 年证券贷款 384，商业票据 185，差距达 2.08 倍。
- 该趋势不仅限于美国；欧洲大银行 1875-1903 年数据也显示证券贷款大幅增长。

### 限制与边界

- 数据仅覆盖纽约市国民银行，不代表全国。
- 商业票据定义可能随时间变化。
- 未区分证券贷款中投机性与投资性用途。
