| 币种 | 首次授权 | 1792年规格 | 关键后续调整 |
|---|---|---|---|
| Half-cent | 1792年4月2日 | 104 grains 纯铜 | 1857年停止铸造 |
| Cent | 1792年4月2日 | 168 grains 纯铜 | 1793年起改为纯铜大尺寸 |
| Half-dime | 1792年4月2日 | 20.8 grains，892.4 | 1837年改为900 fineness |
| Dime | 1792年4月2日 | 41.6 grains，892.4 | 1837年改为900 fineness |
| Quarter Dollar | 1792年4月2日 | 104 grains，892.4 | 1837年改为900 fineness |
| Half Dollar | 1792年4月2日 | 208 grains，892.4 | 1837年改为900 fineness |
| Dollar（标准银元） | 1792年4月2日 | 416 grains，892.4 | 1837年412.5/900；1873年停铸；1878年恢复 |
| Quarter-Eagle | 1792年4月2日 | 67.5 grains，916⅔ | 1834年64.5/899.225；1837年改900 |
| Half-Eagle | 1792年4月2日 | 135 grains，916⅔ | 1834年128/899.225；1837年改900 |
| Eagle | 1792年4月2日 | 270 grains，916⅔ | 1834年258/899.225；1837年改900 |
| Three-Dollar Piece | 1853年2月21日 | 77.4 grains，900 | 1889年停止铸造 |
| Trade Dollar | 1873年2月12日 | 420 grains，900 | 1885年停止流通 |

关键观察：1834-1837年的调整是美国货币史上首次系统性地降低金币实际含金量并统一银币 fineness，这一参数变化在后来围绕金本位与复本位的争论中具有重要地位。
