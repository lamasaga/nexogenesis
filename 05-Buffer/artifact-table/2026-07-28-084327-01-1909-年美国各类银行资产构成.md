### 核心表达

1909 年美国 22,491 家各类银行（州立、国民、私人、储蓄银行及信托公司）的资产构成显示，房地产贷款、其他抵押贷款、其他贷款与贴现、银行间往来以及现金占主要部分。Anderson 用此数据质疑"商业票据是银行正常和主导资产"的传统观点。

### 依据与细节

| 资产项目 | 金额（百万美元） |
|---|---|
| 房地产贷款 | 2,505 |
| 其他抵押贷款 | 3,975 |
| 其他贷款与贴现 | 4,821 |
| 透支 | 69 |
| 美国联邦债券 | 792 |
| 州、县、市政债券 | 1,091 |
| 铁路债券和股票 | 1,560 |
| 其他公共服务公司债券 | 466 |
| 其他股票、债券等 | 703 |
| 应收其他银行和银行家款项 | 2,562 |
| 房地产、家具等 | 544 |
| 支票和其他现金项目 | 437 |
| 库存现金 | 1,452 |
| 其他资产 | 111 |
| **资产总计** | **21,095** |

- 数据来源：Comptroller of the Currency，1909 年。
- 关键观察：
  - "其他贷款与贴现"仅占总资产约 23%，而其中只有一部分是真正流动的商业票据。
  - 房地产贷款占比偏高，部分原因是包含了许多储蓄银行（非商业银行）的数据。
  -  Railroad bonds and stocks 占 1,560 millions；其他股票债券 703 millions。
  - 银行间往来（due from other banks）和现金合计约 4,014 millions，流动性储备可观。
- Anderson 认为，商业银行资产中真正流动的商业票据比例远低于传统观点所暗示的。

### 限制与边界

- 数据混合了商业银行、储蓄银行、信托公司和私人银行，不完全反映商业银行典型资产结构。
- "其他贷款与贴现"内部构成不明，无法直接识别商业票据金额。
- 1909 年数据受当时银行业结构影响，与当代银行业差异大。
