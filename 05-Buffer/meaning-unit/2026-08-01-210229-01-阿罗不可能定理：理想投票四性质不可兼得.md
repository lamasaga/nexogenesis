肯尼斯·阿罗在1951年《社会选择与个人价值》中界定理想投票制应满足：（1）**一致性（Unanimity）**：人人偏好 A 胜 B，则 A 胜 B；（2）**传递性**：A 胜 B 且 B 胜 C，则 A 胜 C；（3）**无关备选独立**：A 与 B 的相对排序不取决于第三人选 C 是否在场；（4）**无独裁者**：无人能无视他人偏好而总定结果。看似可欲且相容，阿罗却数学证明：**没有任何投票制能同时满足全部性质**——即**阿罗不可能定理**。两两多数因孔多塞悖论常失传递性；博尔达计分违反无关备选独立——表1下 B 赢，若去掉 C 只比 A、B，则 A 赢（分数依赖 C 是否参赛）；排序选择亦然——表1下 A 赢，若 B 消失，更多人第一志愿变 C，C 首轮即获多数。定理不只针对这三种简制，而针对任何汇总个人偏好以择结果的方式。

> Arrow proved… that no voting system can satisfy all these properties. This result is called Arrow’s impossibility theorem.
> …there is no method for aggregating individual preferences into a valid set of social preferences.
