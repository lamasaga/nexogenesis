### 核心表达

　　货币数量论的“长期”结论虽可能正确，但长期对当前事务是误导性指南；n 的变化会通过影响 k、k'、r 而对 p 产生非比例反应，尤其在预期自我实现的大规模变动中。

### 依据与细节

　　Keynes 名言：“In the long run we are all dead.” 他以美国内战后的美元为例：若法律将美元价值固定为低于现价 10%，长期 n 与 p 会高 10%，但这对当前风暴中的经济无济于事。实际经验中，n 的变化会反作用于 k 与 r。例如 1900–1914 年各国央行倾向于囤积流入的黄金，提高准备金率 r，使南非黄金增产对物价的影响减弱。农业国农民在通胀早期会增加 hoarding，使价格不按比例上涨。但当 n 的大变化引发同向预期时，p 的变动可能超过比例（恶性通胀）。

### 限制与边界

　　原文未系统估计这些摩擦与预期效应的相对大小；案例说明性质强。

### 原文摘录

> But this long run is a misleading guide to current affairs. In the long run we are all dead.
> A large change in n, which rubs away the initial friction, and especially a change in n due to causes which set up a general expectation of a further change in the same direction, may produce a more than proportionate effect on p.
