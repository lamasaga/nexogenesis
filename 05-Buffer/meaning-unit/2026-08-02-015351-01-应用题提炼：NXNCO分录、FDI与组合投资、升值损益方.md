题组把定义推进到分录与利益方。（1）进出口冲击：美国教授欧洲观光 → 美国进口升、NX 降；巴黎学生看好莱坞电影 → 美国出口升、NX 升；叔叔买菲亚特 → 进口升、NX 降；牛津书店卖本教材 → 美国出口升、NX 升；加拿大公民在佛蒙特购物 → 美国出口升、NX 升。（2）NX vs NCO：美国人买索尼电视 → NX 降（进口）；买索尼股票 → NCO 升（获外国资产）；索尼养老基金买美国国债 → NCO 降（外国人获本国资产）；日本索尼工人买乔治亚桃 → NX 升（出口）。（3）FDI 主动管理（公司更可能），组合投资更被动（个人投资者更常见）。（4）NCO 方向：美国手机公司在捷克设办事处 → NCO 升（FDI）；伦敦 Harrods 股票卖给通用汽车养老基金 → NCO 升（组合）；本田扩建俄亥俄工厂 → NCO 降（外国人在美直接投资）；富达把丰田股票卖给法国投资者 → NCO 降（本国居民减持外国资产）。（5）美元升值：持美国国债的荷兰养老基金高兴（以本币计债券更值钱）；美国制造业不高兴（出口竞争力下降）；赴美澳大利亚游客不高兴（美元更贵）；赴海外买产的美国公司高兴（外币资产更便宜）。
