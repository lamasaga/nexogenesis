Caleb 总成本可拆为两类：**Fixed costs** 不随产量变化，即使产量为零仍发生——如 **rent**（例中 Table 2 固定成本 **$3.00**）、全职记账员薪水（与咖啡产量无关）。**Variable costs** 随产量变化——咖啡豆、奶、糖、纸杯用量，以及为增产额外雇工的 wages：0 杯 → variable cost 0；1 杯 → $0.30；2 杯 → $0.80，依此类推。**Total cost = fixed cost + variable cost**（列 2 = 列 3 + 列 4）。该分解是后续 average cost、marginal cost 等度量的基础。

> A firm's total cost is the sum of fixed and variable costs.
