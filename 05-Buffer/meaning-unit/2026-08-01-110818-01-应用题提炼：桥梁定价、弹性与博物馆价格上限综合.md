Problem 4（桥梁）：建造成本 200 万美元、维护为零，需求表给出各价通行量——利润最大化价非效率价；私企可能因亏损不建；政府若建应择 MC = 0 的效率价（或补贴后的可持续价）。Problem 5：垄断者**永不在需求缺乏弹性段生产**——提价时 TR 升而 TC 可能不变或缓升，但缺乏弹性段 MR < 0，与 MR = MC > 0 矛盾；MR 曲线在需求弹性 = 1 处为零。Problem 6（戏剧票）：成人与儿童分价可榨取更多 CS；禁歧视时须单一价，利润下降，部分消费者（通常为高 WTP 成人）受损、低 WTP 儿童可能受益；固定成本从 2000 升至 2500 改变是否值得开演，但不改变 MR = MC 的边际定价逻辑。Problem 7（经济学博物馆）：ATC 随 Q 下降属天然垄断； lump-sum 税 $24 后免费参观 vs 自负盈亏门票的 CS 与福利分配对比。Problem 8（Potter 水井）：线性 P、MR、MC 求垄断 Q/P；价格上限 10% 或 50% 低于垄断价时，需求量、供给量与**是否短缺**须用 MC 曲线判断——Billy 说上限致短缺只在需求 > 供给时成立。
