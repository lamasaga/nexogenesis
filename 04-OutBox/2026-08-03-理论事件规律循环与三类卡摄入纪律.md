# 摄入–分析循环对齐：三类卡强制产出与相关性两问

> 日期：2026-08-03  
> 性质：知识体使用目标对齐与摄入优化约定（非 Card；指导 compile / digest / talk / emerge）  
> 触发：用户明确知识库用途为「理论 → 突发事件分析 → 发展规律刻画 → 反哺理论」；真实数据可外取，库内要沉淀思考与推理模型

---

## 1. 一句话目标

　　知识库的主产品不是「又多读了一本书」，而是一套可循环使用的推理装置：**用理论透镜读突发事件，从事件中抽出可迁移规律，再用规律收紧或改写理论**。年鉴与外数负责刻度；库内负责模型、剧本与规律候选。

---

## 2. 目标循环（四拍）

```text
① 透镜（理论 / model / claim）
        ↓ 套用
② 事态剧本（阶段 · 触发 · 放大 · 失效）
        ↓ 抽象
③ 规律候选（可迁移命题 · 反例 · 适用域）
        ↓ 多次事件检验后
④ 反哺理论（enrich / conflict / 升格或降级透镜）
        ↑______________________________|
```

| 拍 | 问题 | 产出形态 | 典型来源 |
|---|---|---|---|
| ① 透镜 | 我用什么结构看世界？ | `model` / `claim` / 既有枢纽 | 教材、资产定价、明斯基、传导与中介论文 |
| ② 事态剧本 | 这件事按什么阶段展开？何处放大？何时失效？ | `phenomenon` 或带阶段槽的 `model`；必要时 `conflict` | Kindleberger、R&R、Mehrling、Shin；突发案例深判 |
| ③ 规律候选 | 哪一句命题能搬到下一场事件？边界在哪？ | `claim` 或 `phenomenon`，**maturity: growing** | 跨危机对照、跨市场对照、多次 talk/judge 收敛 |
| ④ 反哺 | 旧透镜要补边、升格、降级还是标张力？ | enrich / `conflict` / Profile 启发式 | 规律候选经 ≥2–3 场独立事件仍成立或系统性失败 |

　　**反模式**：只做 ①（理论堆）；或只有 ② 的新闻叙事却无 ③（故事堆）；或未经验证就把 ③ 标成成熟真理。

---

## 3. 摄入时强制产出的三类卡

　　比「再买什么书」更重要的是：每轮实质性摄入（书、长文、案例链）结束时，自检是否至少触达下列三类之一的**增量**；若整本书只长出更多 ①，视为未对齐目标。

### 3.1 透镜（Lens）

- **职责**：可点名的解释结构——变量、因果方向、适用层级。  
- **类型**：优先 `model`；可争辩立场用 `claim`。  
- **合格标准**：没读过原书的人也能说出「用它看什么、看不到什么」；关键组件写职责，不写名词子弹。  
- **库内已有厚区**：AD-AS / 货币传导、SDF 与因子、明斯基融资层级、流动性螺旋、中介资本约束、相对–绝对定价光谱等。  
- **摄入纪律**：新透镜必须能指出与旧透镜的 `extends` / `conflicts-with` / `based-on`，禁止孤岛新理论。

### 3.2 事态剧本（Episode Script）

- **职责**：把一类事件写成可对照的**阶段剧本**，供下一场突发套用。  
- **最低字段（写进正文，不必新类型）**：  
  1. **阶段**：如繁荣 → 杠杆上升 → 触发 → 挤兑/抛售 → 政策介入 → 余波；  
  2. **触发**：什么冲击或信息披露启动下一阶段；  
  3. **放大**：哪条反馈（保证金、净值、汇率、对标映射、挤兑预期）使冲击非线性；  
  4. **失效边界**：剧本在何种制度/开放度/债权人结构下不适用。  
- **类型**：常为 `phenomenon` 或「带阶段描述的 `model`」；对立剧本升 `conflict`。  
- **主产区**：Kindleberger / Reinhart–Rogoff / Mehrling / Shin；GFSR、央行金融稳定报告中的**机制章节**（非整本年鉴切片）。  
- **合格标准**：换一个国别或资产，仍能用同一套阶段提问——否则只是国别故事，不是剧本。

### 3.3 规律候选（Regularity Candidate）

- **职责**：从剧本与多事件中抽出**可迁移命题**，明确反例与适用域。  
- **正文至少含**：  
  - **命题**（一句话，不复读标题）；  
  - **反例或失败条件**；  
  - **适用域**（资产类、制度、开放度、期限）；  
  - **尚待检验的问题**（可选，可进 Profile 问题清单）。  
- **成熟度**：**默认 `maturity: growing`**；禁止首轮摄入标 `mature`。  
- **升格条件（建议）**：至少经过 **两次以上**独立事件/案例链的 talk 或 judge 仍不被系统性打脸，再经用户确认升格或写入 Profile「决策启发式」。  
- **降级**：反复失败则 `lifecycle: superseded` 或收入 `conflict`，不要静默留在活跃真理层。

### 3.4 三类卡与循环的对应

```text
书/报告/案例
    │
    ├─→ 丰富或新建【透镜】───────────────①
    ├─→ 新建或 enrich【事态剧本】───────②
    └─→ 至多少量【规律候选】growing───③
              │
              └─ 多事件后 → 反哺透镜 / Profile ──④
```

　　**数量纪律**：单波消化宁 enrich 透镜与剧本，也不要批量生产「一条新闻一条规律」。规律候选必须可独立阅读、可被下一场事件证伪。

## 4. 发现「相关性」时的两问（强制）

　　凡声称「A 与 B 相关 / 联动 / 定价权 / 同涨同跌」，在 talk、深判、digest、emerge 中**至少过两问**；能答则写进卡或对话推理，不能答则降级为「观察」而非「规律」。

### 4.1 第一问：统计共动，还是融资/制度造成的内生共动？

| 判断 | 含义 | 优先对接的库内透镜 |
|---|---|---|
| **统计共动** | 同涨同跌可测，但机制未明；可能是共同冲击或偶然 | 先当观察；用 Harvey 式纪律防「假相关升级为因子真理」 |
| **内生共动** | 杠杆、保证金、市值会计、中介资本、共同债权人、制度软约束使相关性在压力下内生抬升 | `市场与融资流动性螺旋`、`中介资本约束定价`、明斯基融资谱系、坏时期因子之辨 |

　　**操作句式（对话与写卡）**：  
　　「此刻看到的相关，有多少能用融资/中介/制度反馈重写？若抽掉杠杆与共同债权人，相关是否还在？」

### 4.2 第二问：相对锚定，还是共同基本面？

| 判断 | 含义 | 优先对接的库内透镜 |
|---|---|---|
| **相对锚定** | 价格由另一市场/另一锚的市价与叙事映射推出（对标、惯例、选美） | `绝对定价与相对定价光谱`、`跨市场对标相对定价`、`选美竞赛与惯例预期` |
| **共同基本面** | 同一现金流、同一风险因子、同一宏观状态进入贴现 | SDF / 因子框架、开放宏观账本、绝对定价端 |

　　**操作句式**：  
　　「若锚市场关掉或映射叙事破裂，本地价格是否仍能用自身基本面站住？还是定价链条会断？」

### 4.3 两问的联合用法（简表）

|  | 相对锚定强 | 共同基本面强 |
|---|---|---|
| **偏统计共动** | 惯例跟涨；易突然脱钩 | 同主题暴露，机制仍可再挖 |
| **偏内生共动** | 锚定 + 杠杆踩踏（最凶的短崩之一） | 真正的风险溢价/危机共动核心区 |

　　分析突发联动时，争取落到四个格子之一，并点名透镜；避免只说「相关性上升」。

## 5. 对各 Skill 的执行提示

### 5.1 compile

- 开窗时区分：机制块（透镜质料） / 案例阶段块（剧本质料） / 作者自认规律块（规律候选质料）。  
- 年鉴与旗舰报告：**只 compile 分析章中的机制与官方判断框架**；大表数字默认外置，需要时写入「典型实例」而非独立空卡。

### 5.2 digest

- 每波结束在 `operation` 说明或内部自检中回答：本波是否 enrichment/新建了透镜、剧本、规律候选中的哪几类？  
- 规律候选一律 `growing`；与已有透镜冲突时优先建 `conflict` 或 `conflicts-with`，不要静默覆盖。

### 5.3 talk / judge

- 突发事件：先选透镜 → 套事态剧本阶段 → 再决定是否提出规律候选。  
- 凡谈联动：显式回答 §4 两问；表达风格仍服从「完整推理优先于术语拼接」（见 `04-OutBox/2026-08-03-talk深判表达风格优化建议.md`）。

### 5.4 emerge

- 用户从实战观察涌现时（如跨市场对标）：优先落为**剧本式 phenomenon** 或**growing 规律候选**，并强制挂上相对定价 / 选美 / 流动性等既有透镜，避免新孤岛。

### 5.5 construct

- 通盘时检查：有无「只有透镜、从无剧本与规律」的域？有无「规律候选长期 growing 却从未被事件再测」？  
- 升格枢纽优先给**反复被剧本调用的透镜**与**多次存活的规律**，而不是给最新论文标题。

## 6. 与书单、年鉴的分工（备忘）

| 材料类型 | 主要喂养 | 不要变成 |
|---|---|---|
| 理论书 / 经典论文 | 透镜 | 无边的概念目录 |
| Kindleberger、R&R、Mehrling、Shin | 事态剧本 + 少量规律候选 | 故事摘抄集 |
| Rodrik 类方法论 | 反哺规则、模型选择纪律 | 空泛科学哲学 |
| IMF/BIS/央行年鉴与旗舰报告 | 年度脆弱性框架、可引用官方剧本片段 | 按页切片的数据卡海 |
| 外数（FRED、统计年鉴表） | 对话与深判时的刻度 | 知识库的主语义源 |

## 7. 最小落地检查清单（可打印）

每轮摄入或每场重大突发事件复盘，勾选：

- [ ] 用到了哪几张**透镜**？（写出 id）  
- [ ] 是否写清或更新了**事态剧本**四件套：阶段 / 触发 / 放大 / 失效？  
- [ ] 是否新增或修订了**规律候选**？是否仍为 `growing`？  
- [ ] 相关性两问是否都答了：内生共动 vs 统计？相对锚定 vs 共同基本面？  
- [ ] 若规律再次被事件支持或打脸：是否安排了 **enrich / conflict / Profile** 反哺？

　　任一项连续多轮为「否」，说明循环在该处断裂——应停书单扩张，先补剧本与规律层。
